# Identidade Oculta

Jogo de investigação criminal interativo dos anos 90 reconstruído em React + TypeScript + Vite + Tailwind CSS.

## Sinopse
Rancho Esperança, 13 de outubro de 1995. Sete pessoas estavam no set de filmagem de uma produção independente. Na manhã seguinte, apenas uma sobreviveu — ou talvez nenhuma das conclusões seja simples.

## Funcionalidades Principais
- **Pasta de Evidências (21 fitas)**: Fotos e laudos periciais tratados em alta resolução, com síntese de voz (Web Speech API pt-BR), forma de onda animada e carretel giratório de fita cassete.
- **Linha do Tempo (Sequência)**: Reconstituição cronológica dinâmica dos fatos com ordenação intuitiva e inspeção rápida.
- **Fichas do Caso (7 personagens)**: Preenchimento das fichas forenses (Ordem de morte, Local, Horário e Causa da morte) para Roberto (Bob), Mônica, Marcos, Dênis, Samuel, Vera e Cláudio.
- **Validação com 5 Finais**: Análise detalhada das deduções com carimbo pericial, porcentagem de acertos em fichas e cronologia, dicas de correção e notas sobre a ambiguidade forense final.
- **RetroSheet 95**: Acesso à planilha Windows 95 autêntica de controle de despesas de produção (`CONTROLE_DESPESAS_PRODUCAO.XLS`).
- **Ferramentas de Teste (Mock / Erro)**: Botões rápidos para carregar gabarito completo ou simulação de erros para validação imediata.

## Execução
```bash
npm install
npm run dev
```
Dev server disponível em `http://0.0.0.0:3000`.
